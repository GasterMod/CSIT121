Lab 05 Update

On the UI design assignment, seeing how much effort goes into making UI good let alone accessible was surprising.

YouTube Specifics

When I looked at youtube, I had to really go out of my way to look for how the UI did things. What lead to what, what lead to where and how many ways could you get to where and did it make sense?

UI Practices

At the end of the day this is how UI should be. It should be natural, clean, and just do what it has to do. Maybe have some fun with it so long as it doesnt impede the user's workflow. But it should always be standardized for the site, have consistency, have multiple ways to view it on different sized screens (mobile phones, laptops, etc.).
